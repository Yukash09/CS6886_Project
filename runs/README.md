# Report runs

This directory contains the lightweight artifacts for the eight experiments
used in `project_report/report.tex`. Run directories follow the naming scheme
generated by the training code:

`<architecture>_<dataset>_<method>_e<epochs>_s<seed>`

Each retained run contains:

- `config.json`: model, method, optimizer, data, and hardware configuration.
- `metrics.csv`: per-epoch training, validation, test, timing, and memory data.
- `summary.json`: validation-selected test result and aggregate resource data.

Large `ckpt.pt` files and verbose `run.log` files are intentionally excluded
from version control and are not required to reproduce the report figures.

The retained experiments are:

- ResNet-20: BP, per-unit LLS, per-unit LLS-MxM, and aligned 4-3-3 LLS-MxM.
- Wide-ResNet-20: BP and two-section 7-3 LLS-MxM.
- ViT-Tiny: BP and six-section 2-2-2-2-2-2 LLS-MxM.

Regenerate the report figures from these artifacts with:

```bash
python project_report/generate_figures.py
```
